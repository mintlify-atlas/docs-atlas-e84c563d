Ara is an open-source vector processing unit developed by the [PULP Platform](https://pulp-platform.org/) at ETH Zurich and the University of Bologna. It implements the **RISC-V Vector Extension v1.0 (RVV)** and operates as a coprocessor to the CVA6 scalar core, delivering scalable vector compute for signal processing, linear algebra, machine learning, and computer vision workloads.

## What is Ara?

Ara is a **modular, scalable vector accelerator** that plugs into RISC-V SoC designs to accelerate data-parallel workloads. It can be configured with 2, 4, 8, or 16 parallel vector lanes, each containing a slice of the vector register file, a SIMD FPU, and a SIMD ALU/multiplier.

## Get started

<Steps>
  <Step title="Clone the repository">
    Clone Ara with all its submodules to get the hardware sources, toolchain, and applications.

    ```bash
    git clone https://github.com/pulp-platform/ara.git
    cd ara
    make git-submodules
    ```
  </Step>
  <Step title="Build the toolchain">
    Build the RISC-V LLVM toolchain with RVV 1.0 support, and the Spike ISA simulator.

    ```bash
    make toolchain-llvm
    make riscv-isa-sim
    ```
  </Step>
  <Step title="Choose a configuration">
    Select a lane configuration (default is 4 lanes with VLEN=4096 bits).

    ```bash
    export ARA_CONFIGURATION=4_lanes
    ```
  </Step>
  <Step title="Run a simulation">
    Build a sample application and simulate it using Verilator or ModelSim.

    ```bash
    cd apps && make bin/hello_world
    cd ../hardware && app=hello_world make simv
    ```
  </Step>
</Steps>
