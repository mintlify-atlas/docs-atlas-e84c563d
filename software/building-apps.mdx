title: "Building and Running Ara Applications"
description: "Compile C and assembly applications for Ara using the RISC-V LLVM toolchain, run them in Spike or RTL simulation, and execute RISC-V vector unit tests."
---

The `apps/` folder contains example applications, benchmarks, and tests ready to run on Ara. Applications are written in C (or C++) and compiled with the RISC-V LLVM toolchain targeting the RVV 1.0 vector extension. Each application lives in its own subdirectory and includes a `main.c` entry point, optional kernel implementations, and a data-generation script.

## Build an application

From the repository root, change into the `apps` directory and invoke `make` with the binary target:

```bash
cd apps
make bin/hello_world
```

The Makefile discovers all `main.c` files automatically, so the same pattern works for every application:

```bash
make bin/fmatmul
make bin/fft
make bin/softmax
```

To select a different lane configuration (e.g. 2 lanes for faster iteration), prepend `config=2_lanes`:

```bash
config=2_lanes make bin/hello_world
```

<Tip>
  Use `config=2_lanes` during development to keep simulation times short. Switch
  to the target configuration (e.g. `config=4_lanes`) when running final
  benchmarks.
</Tip>

## Run with Spike

[Spike](https://github.com/riscv-software-src/riscv-isa-sim) provides fast functional simulation. Build the Spike binary and run it in two steps:

```bash
cd apps
make bin/hello_world.spike
make spike-run-hello_world
```

Spike is invoked with `--isa=rv64gcv_zfh --varch="vlen:<VLEN>,elen:64"` automatically derived from the active configuration. Simulation output is saved to `spike_runs/`.

## Run RTL simulation

After building an application, simulate it against the RTL model using Verilator:

```bash
cd ../hardware
app=hello_world make simv
```

Use `make sim` (ModelSim) or `make simc` (ModelSim without GUI) if you have a commercial simulator available:

```bash
# ModelSim with GUI
app=hello_world make sim

# ModelSim without GUI
app=hello_world make simc
```

## RISC-V vector unit tests

The `apps/riscv-tests/` submodule includes unit tests for scalar CVA6 extensions and RVV vector instructions.

Build all unit tests:

```bash
cd apps
make riscv_tests
```

Run them through the Verilator RTL model:

```bash
cd ../hardware
make riscv_tests_simv
```

CVA6 scalar tests (`rv64ui`, `rv64uc`, `rv64um`, `rv64uf`, `rv64ud`, `rv64si`) are compiled with GCC. Ara vector tests (`rv64uv`) are compiled with LLVM.
